六步主线

按顺序走。第 1 步是地基，第 4 步是重头戏，第 6 步把前面串起来。

  1. 01
    地基01_allocator_traits.cpp

    配置器：容器的地基

    容器不直接 new，那节点和缓冲区从哪来？为什么“分配内存”和“构造对象”要拆成两步？

    验收：能说清 allocate / construct、destroy / deallocate 的顺序，以及 rebind 为什么把 int 配置器变成节点配置器。

    读源码01 看图解6 步
  2. 02
    高频02_vector_internals.cpp

    vector：三根指针与增长曲线

    为什么 push_back 单次可能是 O(n)，摊到每一次却成了 O(1)？扩容之后，哪些东西作废了？

    验收：画出 _M_start / _M_finish / _M_end_of_storage，解释 2 倍扩容、reserve 与 resize 的差别、迭代器失效的边界。

    读源码02 看图解7 步
  3. 03
    结构03_list_deque_internals.cpp

    list 与 deque：节点和分段

    splice 为什么一个元素都不用搬？deque 明明不是连续内存，为什么还能用下标随机访问？

    验收：说出哨兵环的作用、deque 中控器与缓冲区的关系，分清三种容器在两端和中间插入时的失效规则。

    读源码03 看图解7 步
  4. 04
    重头戏04_rbtree_map_internals.cpp

    map / set：红黑树的平衡术

    插入之后，树怎么自己修好？什么时候只变色，什么时候单旋，什么时候要双旋？

    验收：记住五条规矩，能手推三种插入修复；解释 header 为什么让 end() 有实体，以及 operator[] 的插入语义。

    读源码04 看图解7 步
  5. 05
    结构05_hashtable_internals.cpp

    unordered_map：桶、链表与 rehash

    为什么 rehash 之后迭代器全废，指针和引用却还活着？坏哈希会把 O(1) 拖成什么样？

    验收：画出桶数组 + 全局单链表，解释装填因子与质数扩容，能用桶链长度和比较次数说明哈希质量。

    读源码05 看图解7 步
  6. 06
    收口06_iterators_algorithms.cpp

    迭代器与算法：STL 的胶水

    同一句 advance，为什么随机访问只要一步，前向迭代器却要走 1000 步？sort 又为什么要准备三套算法？

    验收：说清五类迭代器与 iterator_traits、标签分派、内省排序的三路切换，以及 lower_bound 与 find_if 的量级差。

每章怎么走

同一个循环，走六遍。不要从第一行源码读到尾。

STEP 01

先跑

编译并运行本章探针，先看输出里哪些数字出乎意料，带着问题再读。

STEP 02

再读

对照教程里的重点，只看成员变量和关键函数，不抠模板细节。

STEP 03

看图

用图解把指针、节点、桶链串起来，单步走到你能自己复述为止。

STEP 04

改探针

换类型、换数量、换哈希，把结论重新跑一遍；输出变了，理解才落地。

读源码不是为了炫技，是为了少踩坑、选对容器、写出能推演性能的代码。 标准规定“保证什么”，源码展示“怎么做到”；别把 _M_start 这种私有名字当成标准。

学完能做到

七条验收标准，来自模块的学习目标。

  • 1说清 STL 六大组件的关系，理解配置器把内存分配和对象构造拆开。
  • 2画出 vector 的三根指针，解释 size / capacity、扩容倍数和迭代器失效。
  • 3说清 list 的哨兵、deque 的中控器与缓冲区，知道何时失效。
  • 4说清 红黑树五条规矩，能手推变色、单旋、双旋三种修复。
  • 5说清 桶数组 + 单链表，理解 bucket_count、装填因子和 rehash。
  • 6理解 迭代器分类与 traits，知道 sort 为什么是内省排序、lower_bound 为什么是 O(log n)。
  • 7能自己写探针程序，用 sizeof、地址和计数器验证源码结论。
